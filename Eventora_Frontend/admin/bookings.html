Awaiting Vendor

Admin is read-only here. A booking's status is decided by the parties to it — the vendor accepts, rejects or completes it; the client cancels it. This page gives the admin visibility, not the ability to overwrite another party's decision. In particular, an accepted booking under a cancelled event is flagged for admin handling, but no refund is issued: the refund workflow is not defined in Database v1.0 and must not be invented.
