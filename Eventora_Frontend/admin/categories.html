Categories

Soft deactivation — services are preserved

EA Eventora Admin Administrator

Demo categories. The 7 seeded categories. Vendor and service counts are derived from the marketplace data, so they match the public pages. Activating or deactivating changes this page only — nothing is saved.

Categories are deactivated, never deleted. services.category_id references categories.id with ON DELETE RESTRICT, so a category that has services cannot be removed from the database at all — the delete would be refused. Deactivation (categories.is_active = 0) is the supported operation: the category disappears from public filters and from new service creation, while every existing service keeps its category and stays bookable. Vendors are never silently delisted.
