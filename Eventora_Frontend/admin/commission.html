Total Vendor Net

The commission model. commission_amount = gross × commission_percentage and vendor net = gross − commission_amount. The default FYP rate is 10%. Vendor net is derived in the query and never stored, so it cannot drift from the commission record. There is deliberately no bookings.platform_commission column — commissions is the single source of truth.
Historical snapshot rule. commissions.commission_percentage is the rate that was actually applied when the booking was placed. It is never recalculated from a vendor's current commission_rate. If the platform rate changes tomorrow, a booking taken at 10% today keeps 10% forever — otherwise past earnings would silently rewrite themselves and the records would no longer be auditable.
No payout lifecycle. Database v1.0 records what each booking earned and the commission taken. It does not model when money moves to a vendor's bank account, so there is no Paid, Pending Payout, Released or Refunded state on this page. Inventing one would make the schema look more complete than it is. payments.status describes a client payment, not a vendor payout.
