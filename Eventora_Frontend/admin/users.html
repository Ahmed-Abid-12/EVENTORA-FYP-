Demo user list. 58 sample accounts assembled from the client and vendor demo data. Blocking changes this page only — nothing is saved.

Blocking is never deletion. Blocking sets users.status = 'blocked'. The row is never removed, because bookings, payments, commissions and reviews hold foreign keys to it with ON DELETE RESTRICT — a delete would fail even if it were attempted, and the platform needs that history for accounting. Blocking a vendor also does not change is_verified; verification is decided on Vendor Approval.
